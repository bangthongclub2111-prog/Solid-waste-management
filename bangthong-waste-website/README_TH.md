# บ้านนี้แยกขยะ อบต.บางทอง

ชุดโค้ดเว็บไซต์ต้นแบบ ฉบับวันที่ 16 พฤศจิกายน 2569

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP ทั้งหมดก่อน อย่าเปิด index.html จากภายใน ZIP
2. เปิดโฟลเดอร์ bangthong-waste-website
3. ดับเบิลคลิก index.html เพื่อทดลองใน Chrome หรือ Edge
   บางเบราว์เซอร์อาจจำกัดการจัดเก็บข้อมูลเมื่อเปิดไฟล์โดยตรง แนะนำวิธีด้านล่าง

## วิธีเปิดผ่านเครื่องตัวเอง (แนะนำ หากติดตั้ง Python แล้ว)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์ที่มี index.html แล้วรัน:

Windows: py -m http.server 8000 --bind 127.0.0.1
macOS / Linux: python3 -m http.server 8000 --bind 127.0.0.1

จากนั้นเปิด http://127.0.0.1:8000 ในเบราว์เซอร์
หยุดเซิร์ฟเวอร์ด้วย Ctrl+C ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## รายละเอียดไฟล์
- index.html: หน้าเว็บ ธีมหลัก การลงทะเบียน ส่งภาพ และตรวจหลักฐาน
- management.js: ทะเบียนกลาง ประชาชน/ร้านค้า อัตรา ถังขยะ คำขอ และงานจัดเก็บ
- printing.js: พิมพ์รายแบบและชุดเอกสารพร้อมสารบัญ
- official-form.js: คำร้องตามแบบ อบต.บางทอง แผนที่ ความเห็น และส่งต่องานจัดเก็บรายได้
- SHA256SUMS.txt: ค่าแฮชของไฟล์โค้ดสำหรับตรวจความครบถ้วน

ทุกไฟล์ JavaScript ต้องอยู่ข้าง index.html ตามลำดับที่อ้างอิงในไฟล์ HTML
ไม่มีขั้นตอน build ไม่มี npm และไม่มีการเชื่อม Google Sheets หรือ API ภายนอก
สามารถนำไฟล์ทั้ง 4 ไปวางบนบริการโฮสต์เว็บแบบ static ได้
การควบคุมการเข้าชมบนเว็บไซต์เดิมเป็นการตั้งค่าของบริการโฮสต์ ไม่ได้รวมใน ZIP

## ฟังก์ชันหลัก
- แยกทะเบียนรับบริการ/ถังขยะ กับการสมัครคัดแยก โดยใช้รหัสผู้ใช้บริการเดิม
- เพิ่มรายเดิมจากสมุดและรายใหม่ แยกประชาชน/ร้านค้า
- กำหนดอัตราค่าบริการรายประเภทหรือเฉพาะราย
- รันเลขถังและเก็บประวัติเปลี่ยนถัง ยกเลิกบริการผ่านคำขอ
- ส่งภาพคัดแยก ตรวจหลักฐาน และติดตามสถานะ
- สร้างรายการเรียกเก็บจำลอง บันทึกส่วนลดที่อนุมัติ สถานะชำระ และ CSV
- พิมพ์ A4 หรือบันทึก PDF จากหน้าต่างพิมพ์ของเบราว์เซอร์

## ขอบเขตของต้นแบบ
ใช้ข้อมูลสมมติเท่านั้น ข้อมูลและภาพจัดเก็บใน localStorage ของเบราว์เซอร์
ข้อมูลไม่ส่งถึง อบต. และไม่ซิงก์ระหว่างเครื่อง เบราว์เซอร์ หรือที่อยู่เว็บไซต์ต่างกัน
การล้างข้อมูลเบราว์เซอร์อาจลบข้อมูลทดลองทั้งหมด พื้นที่เก็บภาพมีขนาดจำกัด
หน้าเจ้าหน้าที่เป็นการสลับบทบาทจำลอง ไม่มีระบบล็อกอินหรือควบคุมสิทธิเจ้าหน้าที่จริง
หมายเลขถังจึงไม่รับประกันความไม่ซ้ำกันระหว่างหลายเครื่อง
ยังไม่ใช่ระบบรับข้อมูลประชาชนจริง ไม่ออกใบเสร็จราชการ และไม่อนุมัติส่วนลดอัตโนมัติ

ก่อนใช้จริงต้องเพิ่มฐานข้อมูลกลาง การยืนยันตัวตน สิทธิฝั่งเซิร์ฟเวอร์
ระบบเก็บไฟล์ สำรองข้อมูล บันทึกตรวจสอบ และกำหนดขั้นตอน/อัตราที่หน่วยงานรับรอง
ข้อความข้อบัญญัติ พ.ศ. 2541 และรายการเอกสารแนบในแบบคำร้องถอดตามต้นฉบับที่ได้รับ
ยังไม่ได้ตรวจยืนยันความเป็นปัจจุบัน ลายมือชื่อในเอกสารเว้นไว้เพื่อลงนามจริง
